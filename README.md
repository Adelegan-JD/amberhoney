# Amber Honey

A premium, mobile-first website for Amber Honey, a brand of Amber Harvest Ventures.

## Stack
- Next.js App Router
- React
- TypeScript
- Custom responsive CSS

## Getting started
```bash
npm install
npm run dev
```

## Configuration
Copy `.env.example` to `.env.local` when Supabase credentials are available. The initial storefront works without a database and uses a locally defined product catalogue.
